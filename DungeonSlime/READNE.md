## 🚀 Tecnologias Utilizadas

- **MonoGame** - Framework para desenvolvimento de jogos

## 📋 Pré-requisitos

- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- [MonoGame](https://www.monogame.net/)

## 🛠️ Instalação e Execução

1. **Clone o repositório**
```bash
git clone https://github.com/seu-usuario/dungeon-slime.git
cd dungeon-slime
```

2. **Restaure as dependências**
```bash
dotnet restore
```

3. **Execute o projeto**
```bash
dotnet run
```
